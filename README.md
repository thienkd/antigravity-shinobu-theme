## 🛡️ Bảo Mật Cấp Doanh Nghiệp (Enterprise Defense-in-Depth)

Dự án được thiết kế theo mô hình phòng thủ nhiều lớp nghiêm ngặt (chi tiết tại [`SECURITY.md`](SECURITY.md)):

1. **Zero NPM Supply-Chain Surface**: Không sử dụng bất kỳ thư viện bên thứ ba nào (`dependencies: {}`); 100% dựa trên thư viện chuẩn của Node.js `>= 22.0.0` và kết nối ngoại tuyến hoàn toàn.
2. **Loopback & Host Pinning**: Máy chủ tài nguyên và telemetry chỉ lắng nghe trên `127.0.0.1` với cổng ngẫu nhiên của hệ điều hành, kiểm tra cứng header `Host` chống tấn công DNS Rebinding (`403 Forbidden`) và không mở CORS đại trà.
3. **256-Bit Ephemeral Closure Token**: Khóa ngẫu nhiên `crypto.randomBytes(32)` sinh mới mỗi phiên trong RAM, truyền kín vào closure cô lập (`__AGY_SEC__`, không bao giờ phơi trên `window`) và xác thực qua header `X-Agy-Token`.
4. **Strict CDP Target Verification**: Xác minh chặt chẽ trang đích là khung Workbench/Launchpad chính chủ của Antigravity trước khi tiêm giao diện — tuyệt đối không chạm vào các trang web mở trong Split Browser.
5. **Chống XSS, Prototype Pollution & Che dấu PII**: Toàn bộ dữ liệu từ `transcript.jsonl` và gói `.agytheme` đều đi qua bộ lọc `stripProtoKeys`, `sanitizeCssUrl`, `sanitizeSvgMarkup` và kết xuất bằng `.textContent`; file `daemon.log` tự động ẩn đường dẫn `$HOME` và UUID phiên làm việc (`chmod 600` trên macOS/Linux).

## 🚀 Hướng Dẫn Cài Đặt Đa Nền Tảng (Windows • macOS • Linux)

> **Yêu cầu hệ thống:** **Git** và **Node.js `>= 22.0.0`** (kiểm tra bằng `node -v`).

### 🪟 Windows (PowerShell)

```powershell
git clone https://github.com/thienkd/antigravity-shinobu-theme.git "$HOME\.gemini\config\skills\antigravity-custom-theme"
powershell -ExecutionPolicy Bypass -File "$HOME\.gemini\config\skills\antigravity-custom-theme\scripts\install-win.ps1"
```

**Lưu ý lần đầu cài đặt trên Windows:**
1. Nhấp chuột phải vào biểu tượng **Antigravity** dưới khay hệ thống (**System Tray**) → chọn **`Quit`** để thoát hẳn tiến trình nền.
2. Mở lại **Antigravity** từ **Start Menu** hoặc **Desktop** *(nếu bạn ghim ứng dụng trên Taskbar, hãy bỏ ghim biểu tượng cũ rồi ghim lại từ Start Menu để nhận cờ `--remote-debugging-port=0`)*.
3. Nhấn nút **`✨ Custom theme`** ở thanh Sidebar bên trái để khám phá kho chủ đề, Lò Rèn `.agytheme`, Chuông gió Điệp Phủ `🎐` và Đạo diễn `🎬 Showcase`!

### 🍎 macOS (`LaunchAgent` tự khởi động ngầm)

```bash
git clone https://github.com/thienkd/antigravity-shinobu-theme.git "$HOME/.gemini/config/skills/antigravity-custom-theme"
bash "$HOME/.gemini/config/skills/antigravity-custom-theme/scripts/install-unix.sh"

- Trình cài đặt tự biên dịch payload bằng Node.js (không cần Xcode Command Line Tools), đăng ký dịch vụ `~/Library/LaunchAgents/io.antigravity.custom-theme.plist` (`chmod 644`) và đặt quyền riêng tư `0600` cho `daemon.log`.
- **Lưu ý quan trọng:** Nhấn **`Cmd + Q`** trên thanh Dock (hoặc chạy `osascript -e 'quit app "Antigravity"'`) để thoát hẳn Antigravity trước, sau đó mở lại kèm cổng CDP cục bộ:
  ```bash

Chỉ cần đóng hẳn Antigravity rồi mở lại từ trình khởi chạy ứng dụng!

## 🛠️ Lệnh Quản Trị, Biên Dịch & Gỡ Cài Đặt Sạch (`NPM Scripts`)

Chạy trực tiếp tại thư mục cài đặt `~/.gemini/config/skills/antigravity-custom-theme`:

| Lệnh | Chức năng chi tiết |
| :--- | :--- |
| `npm run build` | Biên dịch 11 module trong `engine/` + `themes/themes.json` thành `dist/theme_payload.js` (chế độ Hybrid kèm mã băm nội dung `SHA-256` tái lập & kiểm duyệt an toàn SVG). |
| `npm run verify` | Kiểm định trực tiếp qua CDP trên phiên Antigravity đang mở (`themeActive`, `Zero Live Blur`, độ tương phản khung chat & trạng thái các module). |
| `npm start` | Chạy trực tiếp `daemon/theme_daemon.js` ở chế độ foreground để theo dõi hoặc phát triển. |
| `npm run uninstall` | Dừng daemon đã xác thực, gỡ đăng ký tự khởi động trên OS và khôi phục giao diện Antigravity mặc định ngay tức thì (giữ lại cấu hình cá nhân). |
| `npm run uninstall:purge` | Gỡ cài đặt triệt để **100%**: xóa toàn bộ dịch vụ nền, `dist/`, `theme_config.json` và bản sao lưu cấu hình trong `~/.gemini/antigravity/`. |
